# NowPageGen

A minimal micro-tool to generate personal /now pages for indie hackers and creators.

Inspired by the "now" page concept, this tool helps you quickly create a clean HTML page describing what you're currently working on, reading, or exploring.

**Signature: Mourad.Soltani**

## Features
- Simple web form to input your current activities
- Live preview
- Download as HTML
- Health endpoint for monitoring
- Minimal, self-contained

## Quick Start

```bash
pip install -r requirements.txt
python app.py
```

Visit http://localhost:5000

## Tests

```bash
pytest
```
